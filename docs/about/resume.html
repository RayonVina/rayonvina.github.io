Software y datos

Phyto-MAP · Conjunto de datos

Phyto-MAP, a curated database of marine phytoplankton abundance records

Fernando Rayón-Viña, Zoe V. Finkel y Andrew J. Irwin · 2026

Base de datos relacional de abundancia de fitoplancton marino, con observaciones de fuentes bibliográficas, archivos e instituciones integradas en un modelo de datos común. Incluye abundancias estandarizadas y metadatos de muestreo, localización y taxonomía. Disponible en SQLite y CSV.

DOI

Phyto-MAP · Scripts de procesamiento

Phyto-MAP data-processing scripts

Fernando Rayón Viña · 2026

Colección de scripts para el procesamiento de datos de distintas fuentes, la curación taxonómica y la construcción de la base de datos relacional de Phyto-MAP, acompañados de documentación del flujo de trabajo. Documenta los componentes programáticos conservados, no un proceso completo de regeneración de la base de datos.

phytaxr · Paquete de R

phytaxr: Phytoplankton Taxonomic Curation Tools

Fernando Rayón Viña · 2026

Herramientas para la limpieza, estandarización y resolución de nombres taxonómicos de fitoplancton, con funciones de resolución automática y revisión interactiva de coincidencias aproximadas.
